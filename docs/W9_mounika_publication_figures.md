# W9 — Mounika: publication figures, tied to the measurements by test

Branch: `week9/mounika-publication-figures` · Task: **W9-T2**

**Outcome:** `experiments/figures/` was empty; it now holds the three figures the
paper needs, generated by a committed module rather than drawn once by hand. The
design constraint was not "make charts" — it was **make it impossible for a figure
to drift away from the number it claims to plot**.

---

## What I built

### `src/reporting/figures.py`

Every value plotted comes from a committed artefact: a results JSON, a per-clip
score CSV, or a table whose every cell names the document it was measured in. A
figure that quietly disagrees with the paper is worse than no figure, because it
looks authoritative — so `test_english_column_matches_the_retention_json` asserts the
heatmap's English column equals `asvspoof_retention_summary.json` to 0.01 pp. If
someone edits a number in one place and not the other, the build fails.

Matplotlib is imported lazily and forced to `Agg`, so the module imports in CI
(which installs only ruff/pytest/numpy/pandas/pyyaml) and runs headless.

### 1. `system_matrix.png` — the headline

Three systems × three conditions, log-scaled colour because the cells span 0.85% to
54.92% and a linear map renders four indistinguishable dark squares:

| System | English (ASVspoof eval) | Code-mixed clean | Code-mixed channel (G.711) |
|---|---:|---:|---:|
| S1 baseline (English-trained) | 0.85% | 53.71% | 54.92% |
| S2 LoRA (clean-trained) | 8.38% | **1.34%** | 38.58% |
| S2 LoRA (channel-matched) | 4.83% | 13.92% | **3.89%** |

The whole finding in one grid: the English-trained baseline collapses on Hinglish,
the clean adapter fixes that and dies on a phone line, the channel-matched adapter
is the one that holds.

### 2. `det_asvspoof_eval.png` — DET curves from per-clip scores

Computed over the full **71,237-clip** eval partition from the score CSVs, not from
three summary numbers. That matters: a point estimate cannot show that the
channel-matched adapter is better than the clean one *at every operating point*,
which is what the curves make visible.

`det_points()` sweeps every distinct threshold and uses the same bonafide/spoof sign
convention as `metrics.compute_eer`, so the EER marked on each curve and the EER in
the results JSON cannot disagree. The marker lands exactly where each curve crosses
the equal-error diagonal — which is a visual proof the curve maths is right.

### 3. `shortcut_gate.png` — every model number's floor

The low-level-cue gate for CM01 and CM02 against the 50% chance line. It is here
because `lowlevel_cue_check_v1.md` established that no model number on this corpus
can be read without its shortcut baseline beside it: the clean 1.34% sits against a
1.39% baseline and therefore has no margin at all.

## What I deliberately did **not** draw

The plan's figure list also names a cross-eval column, reverse-degradation and
ablations. Those artefacts do not exist and S3 has never been trained. Rather than
leave three silent gaps, `missing_inputs()` reports them and the CLI prints:

```
not drawn -- no measured input exists yet:
  - cross-eval column  (experiments/results/affectdf_crosseval.json)
  - reverse degradation (S3 on English)  (experiments/results/s3_reverse_degradation.json)
  - ablations (XTTS-only vs XTTS+RVC)  (experiments/results/ablations.json)
These are real gaps in the results, not missing plotting code.
```

## Honest limitations

- **The heatmap's non-English cells are hand-entered constants**, each carrying the
  document it came from. Only the English column is machine-checked against a JSON,
  because the code-mixed runs live in several files with different shapes. Those six
  cells are the weakest link and should be wired to their sources when the results
  are frozen.
- **`matrix_markdown()` is hand-rolled** rather than `DataFrame.to_markdown`, which
  needs `tabulate` — not worth growing the CI environment for a table helper.
- **No figure exists for CM02 detection**, because no detector has been scored on
  CM02 yet.
- **The DET x-axis is clipped** to 4× the worst EER, which hides the tails. Fine for
  the paper's operating region, wrong if someone wants the far false-alarm end.

## How to run it
