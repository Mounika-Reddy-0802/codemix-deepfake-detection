Place a call, and watch the receiver get warned

Two separate handsets on two devices. The caller dials, the receiver's phone rings and is answered, and while they talk the detector scores the caller's voice and warns the receiver if it is synthetic. The caller is never told.

Caller device A → dials → Exchange + detector, this server → rings → Receiver device B

Showing this to one person on one screen?

Open the live console instead. It puts both handsets, the signal path and the detector's live analysis on a single screen, which is the view built for an evaluation. Use the two handsets below when you want them on genuinely separate devices.

Running it on two devices

  1. Keep this server running on the laptop.
  2. On the laptop open the receiver handset.
  3. On a phone or second laptop open the caller handset at http://<this-machine>:8000/phone/caller.
  4. Browsers only allow a microphone on localhost or https. For a second device, expose the server over https, for example with ngrok, and use that address.
  5. Both handsets must use the same line name. Add ?room=demo2 to both for a second pair.

No microphone on the second device? Open both handsets in two windows on one machine and have the caller send a prepared clip. The panels stay visually separate.

Three-minute script for an evaluator

  1. A genuine call. Caller sends the real clip or speaks. Receiver accepts and the panel stays green throughout.
  2. A cloned call. Caller picks the XTTS or RVC clip and calls again. Within about six seconds the receiver sees amber, then red at about ten seconds, with a tone and a warning.
  3. The limitation. Caller picks the Tortoise clip, the tool the model never trained on. Say plainly that it is missed over a phone line, and that this is measured, not hidden.
  4. Open the dashboard to show the per-window scores behind the verdict.
