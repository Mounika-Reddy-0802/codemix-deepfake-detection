Join a call

Open this page in two tabs or on two devices on the same network, join the same room, and connect. Each participant's voice is monitored separately; open the dashboard to see the verdicts.

How to demonstrate

  1. Tab A: name "Receiver", microphone. Tab B: name "Caller".
  2. To show a genuine call, Tab B speaks normally.
  3. To show an attack, Tab B chooses An audio file and picks a cloned clip; the clip is played into the call as if the caller were speaking it.
  4. The dashboard shows the caller's verdict change and sounds the warning.

Browsers allow microphone access only on localhost or https. For a second device, expose the server over https (for example with ngrok).
